04从任务发布到结果回收

完成顺序的三个约束

  • 数据、状态和DONE按合同完成EM访问，再生成相应完成事件。
  • 取消在包边界停止；在途EM访问及PHY排空完成后才能形成可回收终态。
  • 终态消费前ET保持owned；软件读取队首不会隐式回收资源。

长度与资源边界

  • 对象指针覆盖起始32KiB，数据指针覆盖起始128KiB，统一2B单位。
  • 260B配置继续有效；完整长度和容量使用独立扩展对象，不扩大旧对象步长。
  • 2047B为wire上限；安全MIC、帧CRC及控制格式可能进一步限制业务长度。
